### Key Takeaway for Demonstration
There are **zero dummy or fabricated endpoints** in the backend router. Every endpoint reads from either:
1. Active in-memory simulation telemetry (`sim_service`).
2. Real SQLite database tables (`traffic_dashboard.db`).
3. Authoritative experiment manifests and evaluation artifacts on disk.
